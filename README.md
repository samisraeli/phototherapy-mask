# מסע פוטותרפיה אישי - Personal PhotoTherapy

מרחב אישי לפוטותרפיה ורפלקציה עצמית, בעברית כברירת מחדל, עם תמיכה גם באנגלית (i18n). האפליקציה בנויה כאתר React / Vite / TypeScript שרץ כולו בדפדפן, ללא שרת וללא התחברות משתמשים.

## תרגילים ומסכים מרכזיים

1. **מסך בית** - פתיח קצר: “מסע פוטותרפיה אישי” ובחירה בין שלושת התרגילים.
2. **דיאלוג עם קלף השלכתי** - תרגיל נשימה וקרקוע, בחירת קלף מתוך חפיסה מטאפורית, שאלה מנחה, בחירת רגשות מרשימה וכתיבת רפלקציה אישית. אפשרות לעיין ולערוך תובנות קודמות לאותו קלף.
3. **צילום מתוך תחושה** - כתיבת התחושה הנוכחת, העלאת תמונה מהמכשיר, ומענה על שאלה מחברת בין התחושה לתמונה.
4. **רצף תמונות אישי** - העלאת 3 תמונות, סידור ברצף אישי, כתיבת הערה לכל תמונה ויצירת נרטיב / משמעות מחברת.
5. **יומן מקומי (Journal History)** - שמירה מקומית ב-`localStorage`, סינון לפי תרגיל, עריכה ומחיקה.

## יכולות נוספות
- תמיכה מלאה ב-RTL (עברית) ו-LTR (אנגלית) עם החלפה מהירה.
- מצב יום / לילה (Light / Dark mode).
- ספירת מילים ותווים בזמן אמת.
- זום וגרירה (Pan & Zoom) על תמונות.
- הגנה בסיסית על קלפי התמונות מפני קליק ימני והורדה.
- ניווט היסטוריה בדפדפן (Back / Forward).
- אינטגרציית Firebase SDK מובנית.

## הרצה מקומית ופיתוח

```bash
# התקנת תלויות
npm install

# הרצת שרת פיתוח מקומי
npm run dev

# בנייה לפרודקשן
npm run build
```

## פריסה ל-Firebase Hosting

הפרויקט מוגדר ישירות מול פרויקט Firebase: `phototherapy-mask`.

```bash
# פריסה מהירה (בונה ומפרסם)
npm run deploy

# או ידנית באמצעות Firebase CLI
npm run build
firebase deploy --only hosting
```
