# שקף צילום - Phototherapy Mask

אפליקציית Web/PWA לתרגיל צילום פוטותרפי עם שקפים וירטואליים.

האפליקציה פועלת כולה בצד לקוח (דפדפן / מובייל), ללא שרת וללא התחברות משתמשים. המשתמש מקבל הנחיה קצרה, בוחר שקף שחור וירטואלי (או יוצר שקף נגטיב אישי משלו), מביט דרך המצלמה במכשיר ומצלם פריים אחד שמחזיק גם הסתרה וגם גילוי.

## יכולות מרכזיות

- **צילום עם שקף:** בחירת שקף מתוך גלריית שקפים מוכנים או שקפים אישיים.
- **יצירת שקף אישי:** הפיכת צילום או תמונה לשקף נגטיב שקוף עם שליטה ברמת שקיפות וניגודיות.
- **מצלמה בזמן אמת:** תצוגת וידאו חיה עם השקף המוצג מעל הפריים, החלפת מצלמה (קדמית/אחורית), צילום בלחיצה אחת.
- **הורדה ושיתוף:** שמירת התוצר למכשיר או שיתוף ישיר.
- **פרטיות מלאה:** כל הנתונים, התמונות והשקפים נשמרים מקומית במכשיר (`IndexedDB` / `localStorage`). שום דבר לא עולה לענן.
- **הגדרות Firebase SDK:** מוטמע ישירות ב-`index.html`.

## כתובת האפליקציה באוויר (Firebase Hosting)

- **קישור ראשי:** [https://phototherapy-mask.web.app](https://phototherapy-mask.web.app)
